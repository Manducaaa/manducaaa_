# MDS/86 — Legacy Terminal

Experiência interativa fictícia em estilo terminal legado/CRT, feita para GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js` para a raiz.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main`, pasta `/ (root)` e salve.
6. Aguarde o GitHub publicar o endereço do Pages.

Não há backend, dependências ou build. O nome e a conclusão são guardados apenas no `localStorage` do navegador. O scanner é explicitamente fictício e não coleta IP, localização ou dados secretos.

## Personalização

Os textos e tempos ficam em `script.js`. As cores, scanlines, CRT e responsividade ficam em `style.css`.
